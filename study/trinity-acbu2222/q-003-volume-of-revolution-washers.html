CALCULUS · Q-003 · WASHER METHOD ★★★★

Volume of Solid of Revolution

$y=\sqrt{x}$ and $y=x^2$, rotated about $y=2$ · Washer method · 2026-05-08

Question

📝 Given

Find the volume of the solid generated when the region enclosed by $y=\sqrt{x}$ and $y=x^2$ is rotated about the line $y=2$.

Strategy — when to use Washers vs Disks

Washer Method (axis is OUTSIDE the region)
$$V = \pi \int_a^b \left[R_{\text{outer}}(x)^2 - R_{\text{inner}}(x)^2\right] dx$$

Use when there's a "hole" — the rotation axis sits outside the region, so each slice is a washer (ring), not a solid disk.

Here: axis $y=2$ is above the region (region lives in $0 \le y \le 1$). Axis is outside → use washers, integrate in $x$.

Step 1 — Find intersection points
Set the curves equal to find the bounds of integration.
$\sqrt{x} = x^2$
Square both sides: $x = x^4$
$x^4 - x = 0 \;\Rightarrow\; x(x^3-1)=0 \;\Rightarrow\; x=0,\,1$

Bounds: $a=0,\;b=1$

Step 2 — Identify upper vs lower curve
On $[0,1]$, which curve is on top? Test a point inside.
At $x=\tfrac{1}{2}$: $\;\sqrt{0.5}\approx 0.707$, $(0.5)^2=0.25$
$\therefore\; \sqrt{x} > x^2$ on $(0,1)$

Upper: $y=\sqrt{x}\quad$ Lower: $y=x^2$

Step 3 — Set up the radii (axis $y=2$ above region)
For any $x \in [0,1]$, distance from axis to a curve = $2 - y_{\text{curve}}$. Whichever is FARTHER from axis = outer; closer = inner.
Lower curve $x^2$ is FARTHER from $y=2$ (smaller $y$, larger $2-y$)
Upper curve $\sqrt{x}$ is CLOSER

$R_{\text{outer}}(x) = 2 - x^2$
$R_{\text{inner}}(x) = 2 - \sqrt{x}$
Step 4 — Set up and expand the integral
$V = \pi \displaystyle\int_0^1 \left[(2-x^2)^2 - (2-\sqrt{x})^2\right] dx$
Expand each square
$(2-x^2)^2 = 4 - 4x^2 + x^4$
$(2-\sqrt{x})^2 = 4 - 4\sqrt{x} + x$
Difference: $(4 - 4x^2 + x^4) - (4 - 4\sqrt{x} + x)$
$= x^4 - 4x^2 - x + 4\sqrt{x}$
Step 5 — Integrate term by term
$\displaystyle V = \pi \int_0^1 \left(x^4 - 4x^2 - x + 4x^{1/2}\right) dx$

$= \pi \left[\dfrac{x^5}{5} - \dfrac{4x^3}{3} - \dfrac{x^2}{2} + \dfrac{8x^{3/2}}{3}\right]_0^1$
Note on $\int 4\sqrt{x}\,dx$
$\displaystyle \int 4x^{1/2}\,dx = 4 \cdot \dfrac{x^{3/2}}{3/2} = \dfrac{8x^{3/2}}{3}$
Step 6 — Evaluate at bounds
At $x=1$: $\;\dfrac{1}{5} - \dfrac{4}{3} - \dfrac{1}{2} + \dfrac{8}{3}$

Group: $\dfrac{1}{5} + \left(\dfrac{8}{3} - \dfrac{4}{3}\right) - \dfrac{1}{2} = \dfrac{1}{5} + \dfrac{4}{3} - \dfrac{1}{2}$

Common denom $30$: $\;\dfrac{6}{30} + \dfrac{40}{30} - \dfrac{15}{30} = \dfrac{31}{30}$

At $x=0$: all terms $= 0$

$V = \dfrac{31\pi}{30}$

✅ Decimal check
$V \approx \dfrac{31 \cdot 3.14159}{30} \approx 3.246$ cubic units
Region area is small (~0.33 sq units between curves), revolved at distance 1.5–2 from axis → volume on order of 3 makes sense.

Common Mistakes

⚠ The 5 traps that cost points on washer problems
  • Forgetting to subtract from the axis
    Radius is NOT $\sqrt{x}$ or $x^2$ directly. It's $2 - y$ because the axis is at $y=2$. If axis were $y=0$ (the x-axis), radius would just be $y$.
  • Swapping outer and inner radius
    The curve FARTHER from the axis = outer. Here axis is ABOVE, so the LOWER curve ($x^2$) is farther. If axis were below, the upper curve would be outer.
  • Squaring before subtracting
    $(R_o^2 - R_i^2) \neq (R_o - R_i)^2$. Always square each radius separately, then subtract.
  • Wrong antiderivative for $\sqrt{x}$
    $\int x^{1/2}\,dx = \dfrac{x^{3/2}}{3/2} = \dfrac{2x^{3/2}}{3}$, NOT $\dfrac{x^{3/2}}{2}$. Bump exponent by 1, divide by new exponent.
  • Missing the $\pi$ factor
    The $\pi$ is OUTSIDE the integral. Easy to drop in the final answer. Always write $V = \pi \int \ldots$ from the start.
💡 Key Takeaway — washer method in 30 seconds
  • Axis outside region → washer method. Axis on boundary → disk.
  • Radius = distance from axis to curve. If axis is $y = c$, radius $= |c - y_{\text{curve}}|$.
  • Outer = farther curve, Inner = closer curve. Always relative to the axis.
  • Formula: $V = \pi \int_a^b (R_o^2 - R_i^2)\,dx$ — square each separately.
  • Integrate carefully: $\int x^n\,dx = \dfrac{x^{n+1}}{n+1}$ — works for fractional $n$ too.
  • Sanity check: convert to decimal, see if magnitude is reasonable for the geometry.
